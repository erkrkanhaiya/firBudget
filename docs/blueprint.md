# **App Name**: ShareSync

## Core Features:

- Expense Input: User-friendly interface for adding expenses with title, amount, payer, and participants. Supports equal or unequal splits.
- Debt Tracking: Displays current debts, showing amounts owed or owing within groups or among friends. Totals should update automatically whenever information changes.
- Settle Up: Records when a payment is made, and updates the user debts accordingly
- Group Management: A central list of groups a user belongs to

## Style Guidelines:

- Primary color: A muted teal (#63BFAF) to inspire trust and collaboration, reminiscent of calm financial management.
- Background color: Light gray (#F0F4F3), provides a clean, unobtrusive backdrop that enhances readability and focus on the numbers, avoiding visual fatigue during expense tracking.
- Accent color: Soft yellow (#D6C128) for interactive elements and important alerts. Offers enough visual contrast to catch the user's eye without overwhelming the calm aesthetic.
- Clean, sans-serif font to maintain a modern and readable design.
- Simple, outlined icons for intuitive navigation.
- Minimalist layout with clear sections for expenses, debts, and group details.
- Gentle transitions for adding or settling expenses, providing subtle feedback.
