# **App Name**: HisabKaro

## Core Features:

- User Profile: Simple user profile creation/edit (name, optional avatar).
- Group Management: Group creation and management.
- Expense Input: Easy expense input with amount, payer, and participants.
- Balance Tracking: Clear display of who owes whom in each group.
- Record Payments: Record cash payments within the app to settle balances.
- Record Payments Notification: Send push notification for payment records.
- Offline & Sync Support: Save expenses offline Sync when back online
- Notifications: When someone adds an expense When you’re added to a groupWhen a payment is recorded
- Activity Log: Track all actions in a group: added expense, settled payment, edited expense Show timestamps
- Settle Up: Record a payment (cash, UPI, bank) Link to payment providers (UPI intent, PayPal, Venmo – optional) Mark debt as paid
- Debts and Balances: Track who owes whom Auto-calculated balances Individual Split summaries: “You owe X to Y” “Y owes you Z” Group summary Individual summary
- Friends & Groups: Add friends by email or username Create groups (e.g., “Europe Trip”, “Roommates”) Invite members to groups Group photo/name/description

## Style Guidelines:

- Primary color: Light blue (#5DADE2) to convey trust and stability.
- Background color: Very light blue (#EBF5FB), almost white, to provide a clean backdrop.
- Accent color: Soft purple (#A9CCE3), which sits closely next to light blue on the color wheel, for interactive elements and highlights.
- Clean and modern font for all text elements to ensure readability.
- Simple, minimalist icons for navigation and actions.
- Clear visual hierarchy to focus on the essentials.
