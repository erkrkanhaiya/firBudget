# **App Name**: BudgetFlow

## Core Features:

- Transaction Logging: Allow users to input and categorize their income and expenses.
- Data Visualization: Display spending data via charts for quick analysis.
- Budget Setting: Enable users to set monthly budget goals per category.

## Style Guidelines:

- Primary color: Soft teal (#4DB6AC) for a calm and trustworthy feel.
- Secondary color: Light gray (#EEEEEE) for backgrounds and subtle accents.
- Accent: Green (#A5D6A7) for positive spending trends and goal achievements.
- Clean, card-based layout for easy navigation and data overview.
- Use clear and consistent icons to represent different spending categories.
- Subtle transitions and animations to provide feedback and enhance user experience.
